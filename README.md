# Веб-сервер авторизации и обратной связи на Native Python

Учебный проект в рамках выполнения лабораторной работы по созданию легковесного веб-сервера без использования сторонних веб-фреймворков. Интерфейс построен с применением адаптивной верстки **Bootstrap 5** и пакета иконок **Bootstrap Icons**.

## 🛠️ Стек технологий
* **Язык разработки:** Python 3.10+
* **Управление зависимостями:** Poetry
* **Базовый модуль сервера:** `http.server` (встроенный)
* **Интерфейс:** HTML5, CSS3, Bootstrap 5 (CDN)
* **Качество кода и тесты:** Black, Isort, Flake8, Pytest, Pytest-cov

## 🚀 Установка и запуск

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone <url_вашего_репозитория>
   cd BootstrapHW_1
   ```

2. **Установите зависимости среды разработки через Poetry:**
   ```bash
   poetry install
   ```

3. **Запустите веб-сервер:**
   ```bash
   poetry run python src/server.py
   ```
   После запуска сервер станет доступен локально по адресу: [http://localhost:8000](http://localhost:8000).

## 🧪 Тестирование и проверка качества (QA)

### Форматирование кода и статический анализ
Проект полностью соответствует стандартам PEP 8. Для проверки и форматирования используются следующие инструменты:

```bash
# Автоматическая сортировка импортов
poetry run isort .

# Форматирование исходного кода под стандарт Black
poetry run black .

# Проверка линтером на статические ошибки
poetry run flake8 .
```

### Запуск тестов и оценка покрытия (Coverage)
Запуск тестов и генерация сводного отчета о покрытии строк кодом:

```bash
poetry run pytest --cov=src --cov-report=term-missing
```
